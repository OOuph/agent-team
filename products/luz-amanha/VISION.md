# Luz Amanhã — VISION

**Статус:** черновик 2026-11-02; утверждает владелец. Этот файл читают все роли: PO решает только внутри него.

## Что это
Сайт `luz.bymachines.ai`: каждый день после публикации OMIE (≈ 13:00–14:20 по Мадриду) — цена электричества в Португалии на завтра по часам (оптовая цена day-ahead, €/MWh) и три самых дешёвых и три самых дорогих часа подряд: когда включать стиралку, бойлер, зарядку машины. PT первым, EN ниже. Единственный из трёх сайтов пилота вне dev-пузыря и с естественной привычкой возврата на следующий день.

## Для кого и зачем
| Пользователь | Приходит с | Получает | Успех |
|---|---|---|---|
| Житель Португалии на индексированном тарифе (Coopérnico, Luzboa, EDP/Galp indexado) | «во сколько завтра дешевле?» | зелёное окно 3 часов + таблица 24 ч за 10 секунд | вернулся на следующий день |
| Владелец электромобиля / солнечных панелей / бойлера с таймером | пост в Telegram 14:00 или 07:00 | часы для зарядки/нагрева; подписка на канал | подписался на Telegram |
| Экспат (EN) | поиск «electricity price tomorrow Portugal» | то же на английском, без регистрации | повторный визит, внешняя ссылка |
| Агент / скрипт / другой бот | `/tomorrow.json`, `/feed.xml`, `/llms.txt` | 24 часа в JSON с окнами и датами | регулярные запросы JSON не от нас |

## Что обещаем и чего не обещаем
- **Решение владельца 02.11: на пилоте только сырая цена OMIE** (€/MWh и прямой пересчёт в €/kWh energia); оценка с надбавками ERSE не показывается всю неделю, `config/tariff.json` остаётся выключенным.
- На каждой странице: «Feito por agentes de IA (agent-team) sem edição humana · responsável: Dmitriy, bymachines.ai» + EN. Никакого сбора персональных данных, форм, трекинга людей, JS, cookies.
- Адреса страниц не меняются (`/`, `/d/YYYY-MM-DD/`, `/tomorrow.json`, `/today.json`, `/feed.xml`, `/llms.txt`, `/legal/`, `/go/telegram/`); данные датированы; источник каждого числа назван (OMIE, файл `marginalpdbcpt_YYYYMMDD.1`, колонка Португалии).
- **Сырая цена €/MWh — факт** (цена OMIE без изменений; час = среднее четырёх четвертей). **€/kWh с надбавками — оценка**, показывается только с подписью «estimativa, não é a sua fatura», датой снимка и источником надбавок (ERSE), которые задаёт владелец в `config/tariff.json`; пока не заданы — показываем только OMIE и прямой пересчёт €/MWh → €/kWh «energia».
- Если данных на завтра нет — страница говорит об этом («OMIE publica por volta das 13:00; próxima tentativa 13:45 UTC») и показывает сегодня; `tomorrow.json` отдаёт `available: false`.
- Чего не делаем: не советуем тариф или поставщика; не даём финансовых рекомендаций и не обещаем экономию; не считаем чей-то счёт; не пишем в Reddit r/portugal / r/PortugalExpats (правила против ботов) и в Facebook-группы; не копируем виджеты и приложения конкурентов (Coopérnico, Luzboa, сайты «preço da luz amanhã») — наш угол только «три окна + EN/PT + Telegram + JSON для агентов»; не вводим надбавки без владельца.

## Ежедневная работа команды
- **13:15 и 13:45 UTC** — `python3 build.py` на сервере: скачать файл OMIE на завтра (кэш `data/omie/`), собрать `public/`, закоммитить `data/` и `public/`, опубликовать. День без обновлённой страницы на завтра к 14:30 UTC при доступном файле OMIE = дефект.
- **≈ 14:00 UTC** — пост в Telegram (главный) и Bluesky на PT и EN: «Luz amanhã (DD.MM): mais barato HH–HH (média N €/MWh) e HH–HH; mais caro HH–HH (N €/MWh). Gráfico por hora: luz.bymachines.ai. Publicado por um agente de IA; responsável: Dmitriy.» Числа берутся из `tomorrow.json`, не из текста.
- **07:00 UTC** — утренний пост «hoje: horas mais baratas HH–HH e HH–HH» из `today.json`.
- **QA после сборки:** 23 или 24 (25 в день перевода часов) значения без NaN; дата в заголовке = завтра; дешёвое окно ≤ среднего ≤ дорогого; тексты PT/EN совпадают по числам; подвал с раскрытием ИИ на каждой странице; `tomorrow.json` отдаётся.
- **Аналитик (00:30 UTC):** люди / краулеры / агенты по логам, возвраты, доля PT vs EN, клики `/go/telegram/`, запросы `/tomorrow.json`.
- **PO:** тест формулировок поста (PT vs EN первым, число vs картинка), «калькулятор своей надбавки» только если спрос виден в логах; задачи разработчику — терпимый парсер, повторная загрузка файлов моложе 48 ч (OMIE иногда перевыкладывает под тем же именем), картинка-график для постов, fallback REN.

## Глубина доработок (решение владельца 02.11: разрешено до L3)
| Уровень | Что | Кто решает |
|---|---|---|
| L0 | данные обновляются каждый день; день без обновления — дефект P1 | PO автоматически |
| L1 | исправления дефектов, найденных персонами, ревьюером, аналитиком, обратной связью | PO автоматически |
| L2 | небольшие функции из наблюдений: фильтры, страницы, срезы RSS/JSON, ссылки голосования и обратной связи | PO автоматически |
| L3 | доставка машинам: MCP-обёртка поверх существующих JSON (по образцу errata-mcp), публикация в реестр MCP и npm, llms.txt | PO автоматически |
| L4 | новые источники данных, новые продукты, аккаунты, платное, отдельный серверный API | только владелец |
