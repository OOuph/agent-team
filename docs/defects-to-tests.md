# Журнал: дефект → проверка

Правило в `CONTRIBUTING.md`: живой дефект сначала воспроизводится красным тестом, потом чинится; если тест написать
нельзя, он становится порогом проверки первого цикла. Строка сюда добавляется тем же PR, что и исправление.

«Доказано» значит: исправление отменено локально, тест прогнан и стал красным, код восстановлен.
