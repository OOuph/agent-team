# Бриф: «Два флота» (пример для сухого прогона)

Хочу пошаговую тактическую игру на двоих в браузере. Поле 8×8, у каждого по пять кораблей с разной дальностью хода и
выстрела, ходят по очереди, партия минут на десять. Входить без регистрации: один создаёт комнату, второй заходит по
коду. Потом, если зайдёт, — ник и рейтинг. Деньги пока не нужны. Играть должно быть удобно и с телефона.
